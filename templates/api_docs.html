🔌 API Documentation

Website Security Check API

This REST API allows an external device or application to submit a public website URL and receive its security header analysis.

Endpoint:

POST /api/check

Request JSON:

{
    "url": "https://example.com"
}

Successful response:

{
    "success": true,
    "url": "https://example.com",
    "score": 1,
    "maximum_score": 5,
    "security_headers": {
        "HTTPS": true,
        "HSTS": false,
        "Content Security Policy": false,
        "X-Frame-Options": false,
        "X-Content-Type-Options": false
    },
    "scan_id": 1,
    "scanned_at": "2026-10-05T12:00:00"
}

How to use it:

Send a POST request to /api/check with a JSON body containing a public website URL.

This tool checks basic HTTP security headers only. It is not a complete vulnerability scanner.
